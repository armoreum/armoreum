# Support

- General questions: support@armoreum.io
- Reproducible bugs and feature requests: https://github.com/armoreum/armoreum/issues
- Vulnerabilities: report privately as described in [SECURITY.md](SECURITY.md).
- Related contracts: https://github.com/armoreum/armoreum-contracts

Never send private keys, passwords, tokens, seed phrases, recovery capsules, or customer data to support or public issues.
